إعداد تطبيق ZTE Config على PythonAnywhere

هذه الصفحة مخصصة لحساب المستخدم mumost. اضغط زر نسخ بجانب الأمر أو الكود، ثم الصقه في المكان المحدد. نفّذ أوامر Bash بالترتيب.
في الصورة كان المسار القديم /home/mumost/mysite، وخانة Virtualenv فارغة. سنغيرهما إلى مسار مشروع ZTE الصحيح.

أولاً: أوامر Bash

ثانياً: إعداد صفحة Web

  1. افتح تبويب Web.
  2. في قسم Code غيّر Source code إلى المسار التالي:
/home/mumost/zte-config

اجعل Working directory أيضاً نفس المسار:

/home/mumost/zte-config

في خانة Virtualenv الصق:

/home/mumost/.virtualenvs/zte-env

بعد اللصق اضغط Enter وانتظر حتى يقبل PythonAnywhere المسار.

ثالثاً: ملف WSGI

اضغط رابط WSGI configuration file، احذف كل المحتوى، الصق الكود التالي، ثم اضغط Save:

import sys

project_path = "/home/mumost/zte-config"

if project_path not in sys.path:
    sys.path.insert(0, project_path)

from app import app as application

رابعاً: تشغيل الموقع

  1. ارجع إلى تبويب Web.
  2. اضغط الزر الأخضر Reload.
  3. افتح الرابط:
https://mumost.pythonanywhere.com

خامساً: اختبار التطبيق

اختر ملف config.bin، اترك المفتاح على Default، ثم اضغط فك التشفير.

إذا ظهرت صفحة ZTE Config Studio فالإعداد نجح.
