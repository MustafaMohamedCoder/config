أوامر نشر ZTE Config على PythonAnywhere

اضغط زر «نسخ» بجانب أي أمر، ثم الصقه في Bash Console. نفّذ الأوامر بالترتيب.

كود ملف WSGI

import sys

project_path = "/home/mumost/zte-config"

if project_path not in sys.path:
    sys.path.insert(0, project_path)

from app import app as application

/home/mumost/.virtualenvs/zte-env
