تشغيل ZTE Config على PythonAnywhere

اضغط زر نسخ بجانب كل أمر، ثم الصقه في Bash Console واضغط Enter. نفّذ الأوامر بالترتيب وانتظر انتهاء كل أمر.
ظهرت لديك رسالة أن مجلد البيئة غير موجود. لذلك سنستخدم mkvirtualenv بدلاً من أمر venv.

كود ملف WSGI

من تبويب Web افتح WSGI configuration file، احذف كل ما بداخله، ثم انسخ الكود التالي والصقه واحفظه.

import sys

project_path = "/home/mumost/zte-config"

if project_path not in sys.path:
    sys.path.insert(0, project_path)

from app import app as application

مسار Virtualenv

ضع هذا المسار في خانة Virtualenv داخل تبويب Web.

/home/mumost/.virtualenvs/zte-env

بعد الإعداد

اضغط Reload في تبويب Web ثم افتح:

https://mumost.pythonanywhere.com
